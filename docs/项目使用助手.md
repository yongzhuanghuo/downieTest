# 项目使用助手（怎么跑起来 / 怎么排查）

这是整个仓库的**操作手册**：怎么启动、怎么看日志、怎么部署、怎么排查。
按「你在哪一端」查对应章节即可。命令和路径都来自仓库真实结构，不写死密码 / IP。

---

## 0. 目录速查（改代码前先知道在哪）

| 你要动的东西 | 目录 |
|---|---|
| Flutter 桌面端（macOS / Windows） | `apps/desktop/` |
| uniapp 移动端（安卓 / 小程序 / H5） | `apps/mobile/` |
| 鸿蒙 PC（占位，未开发） | `apps/harmony-pc/` |
| 统一服务端（授权 + 视频处理 + 管理后台 API） | `services/api/` |
| 管理后台前端（pure-admin-vue3） | `apps/admin-web/` |

> 命令必须在对应子目录里执行。在仓库根跑 `flutter pub get` / `uvicorn` / `npm` 会失败。

## 1. 环境准备

| 依赖 | 用途 | 验证 |
|---|---|---|
| Flutter SDK | 桌面端 | `flutter --version` |
| Node 20+ | 抖音 a_bogus 签名子进程、admin-web 构建 | `node -v` |
| Python 3.10+ | 统一服务端 | `python3 --version` |
| ffmpeg / ffprobe | 视频处理、合并、去水印 | `ffmpeg -version` |
| MySQL 8 | 授权数据 | `mysql --version` |
| Redis | 任务队列 / 频控（可选，见 §6） | `redis-cli ping` |
| pm2 | 服务端进程守护 | `pm2 -v` |

### .env 配置（服务端）

完整 `.env` 模板见 [docs/env-template.md](env-template.md)，复制粘贴后把占位符改成真实值。
关键必填：`DB_*`（连库）、`JWT_SECRET`（登录安全）、`ADMIN_PASSWORD`（后台密码）。

`.env` 不进 git。改密码/端口只改 `.env`，重启服务生效。

## 2. macOS 本地跑桌面端

```bash
cd apps/desktop
flutter pub get
flutter run -d macos --dart-define=API_BASE=http://<服务器IP>:3000
```

- 开发态 yt-dlp / ffmpeg 走系统 PATH（找不到时自动探测 `/opt/homebrew/bin` 等）。
- 首次运行会从 `assets/bin/` 提取二进制到应用支持目录。
- 常见启动报错：
  - 引擎未就绪 → 没装 ffmpeg/yt-dlp：`brew install ffmpeg`，yt-dlp `brew install yt-dlp`
  - 连不上后端 → 检查 `API_BASE` 和服务器安全组放行 3000

### 桌面端日志在哪（重要）

打包版双击启动没有控制台，`debugPrint` 会被写到文件：

- **macOS**：`~/Library/Application Support/com.example.downieTest/logs/app_YYYYMMDD.log`
- **Windows**：`%APPDATA%\com.example.downieTest\logs\app_YYYYMMDD.log`（或安装目录附近）

按天一个文件。排查「打包后不工作」就看这个文件，别只看控制台。

## 3. 桌面端打包 + 排查

```bash
cd apps/desktop
flutter build macos    # 产物：build/macos/Build/Products/Release/4KDownle.app
flutter build windows  # 产物：build/windows/x64/runner/Release/
```

**打包前必查**：`assets/bin/{macos,windows}/` 下的 ffmpeg + yt-dlp 是否在。
这两个二进制被 .gitignore 忽略、不进库，CI 会自动下载；本地打包要自己放进去。

**打包后排查清单**：
1. 双击打开，看日志文件（§2 的路径）有没有 `引擎未就绪` / `提取失败`
2. 图标 / logo 没进包 → 重新跑 `bash tools/generate_icons.sh`
3. 内嵌二进制没提取 → 检查 `assets/bin` 是否为空（开发态为空会回退 PATH，打包版不会）

## 4. 手机端本地测试

先起后端（见 §6 本地起服务），再起前端：

```bash
cd apps/mobile
npm install
npm run dev:h5          # H5：浏览器访问 http://localhost:5173
```

- 真机测试：手机和电脑连同一 WiFi，把 `src/api/index.js` 里的 `127.0.0.1:8000` 改成电脑局域网 IP（`ifconfig` 查），用手机浏览器访问 H5。
- 微信小程序：`npm run dev:mp-weixin`，用微信开发者工具打开 `dist/dev/mp-weixin`。
- 安卓 App：`npm run dev:app` 后需 HBuilderX 云打包或离线打包。

**前端日志**：H5 用浏览器 F12；小程序用 vConsole 或开发者工具控制台。

## 5. 手机端部署

- **H5**：`npm run build:h5` → 产物 `dist/build/h5`，扔到任意静态服务器 / Nginx。后端地址改成真实域名（`src/api/index.js` 或 `PUBLIC_BASE_URL`）。
- **小程序**：`npm run build:mp-weixin` → 微信开发者工具上传；小程序后台配置 request / uploadFile 合法域名，`src/manifest.json` 填 `mp-weixin.appid`。
- **安卓 APK**：HBuilderX 云打包，`manifest.json` 填 appid。

## 6. 服务端运行与部署

### 本地跑

```bash
cd services/api
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env && vim .env     # 填 DB / ADMIN / JWT / REDIS
uvicorn app.main:app --reload        # 默认 3000，本地调试
```

- 只跑媒体模块（不需要 MySQL）：`MODULES=media uvicorn app.main:app --port 8000`
- 健康检查：`curl http://127.0.0.1:3000/health`

### 服务器部署（pm2）

```bash
cd services/api
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
# 装系统依赖：apt install -y ffmpeg nodejs  （抖音签名要 node）
.venv/bin/python scripts/init_db.py         # 建表（幂等，可重复跑）
.venv/bin/python scripts/generate_licenses.py -c 10 -t perpetual -o pro.csv   # 生成激活码

pm2 start ".venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 3000" --name api
pm2 save && pm2 startup
```

### 看日志（服务器）

```bash
pm2 logs api                 # 实时
pm2 logs api --lines 100     # 最近 100 行
pm2 logs api --err           # 只看错误
```

日志内容：解析/下载/去水印关键步骤、未捕获异常堆栈、MySQL/Redis 连接失败。

## 7. 管理后台

```bash
cd apps/admin-web
```

访问 `http://<服务器IP>:3000/admin/`，账号密码是 `.env` 里的 `ADMIN_USERNAME` / `ADMIN_PASSWORD`。

## 8. 常见问题排查

| 现象 | 排查 |
|---|---|
| 端口被占用 | `lsof -i :3000`，换 `PORT` 或杀掉占用进程 |
| MySQL 连不上 | `.env` 的 `DB_HOST/PORT/USER/PASSWORD/NAME`；`mysql -h127.0.0.1 -u... -p...` 手动试 |
| Redis 连不上 | `redis-cli ping` 应回 `PONG`；查 `REDIS_HOST/PORT/PASSWORD` |
| 抖音解析失败 | 服务器没装 `node`（a_bogus 签名要起 node 子进程） |
| 视频处理报错 | 没装 `ffmpeg`/`ffprobe`；`PIL` 报错 → `pip install Pillow`（旧 requirements 漏过） |
| 下载/解析 403 | 签名 URL 过期或 `sig` 不匹配（`SIGNED_URLS=1` 时 `/files` `/tmp` 要带签名） |
| CORS 报错 | `.env` 的 `ALLOWED_ORIGINS` 白名单没包含前端域名 |
| 打包后桌面端不工作 | 看日志文件（§2），不是看控制台 |

## 10. 阿里云服务器：建表 / 进 Docker MySQL

> MySQL 跑在阿里云服务器的 Docker 里，**3306 没对外开**，所以建表脚本只能在**服务器上**跑，不能在自己电脑跑。

### 10.1 把代码弄到服务器（首次）

服务器从 Gitee（`origin`）拉代码，`git pull` 后就有了 `services/api/`：

```bash
ssh root@<服务器IP>
cd <你部署的仓库目录>     # 例如 ~/4KDownle 或 ~/downie_test
git pull origin main
```

### 10.2 在服务器上跑建表脚本（建表 + 种子，一步到位）

```bash
cd services/api

# 首次：建虚拟环境装依赖
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 确认 .env 已就位（DB_HOST 填 127.0.0.1，指向本机 Docker MySQL）
ls -la .env

# 建表 + 写种子（幂等，可重复跑）
.venv/bin/python scripts/init_db.py
```

输出应看到两行：
```
✅ 数据表已创建/更新（N 条语句）
✅ 种子数据已写入（超级管理员角色 + 菜单树 + 默认账号 admin）
```

> ⚠️ 只灌 `sql/schema.sql` 不够——那只是空表，`admin` 账号、角色、菜单是 `init_db.py` 里的 Python 逻辑写进去的。必须跑 `init_db.py`。

### 10.3 进 Docker MySQL 容器（排查/核对用，不是建表必需）

```bash
# 1. 看容器名（老项目叫 mysql-mysql-1）
docker ps

# 2. 进入 MySQL 容器登录（会让你输 root 密码）
docker exec -it <容器名> mysql -uroot -p

# 3. 登录后核对库和表
SHOW DATABASES;                       # 应能看到 .env 里 DB_NAME 的库
USE <DB_NAME>;                        # .env 的 DB_NAME
SHOW TABLES;                          # 应有 9 张表（licenses/device_bindings/unbind_log + sys_* 6 张）
SELECT username FROM sys_users;        # 应能看到 admin
```

退出容器内 MySQL：输入 `exit`。

### 10.4 如果不想 SSH 用 Python，也可以容器内直接灌 SQL（仅建表、不含种子）

```bash
# 把 schema.sql 传进容器再导入（不推荐，缺种子数据）
docker cp services/api/sql/schema.sql <容器名>:/schema.sql
docker exec -it <容器名> mysql -uroot -p <DB_NAME> < /schema.sql
```

> 但这样只有空表，`admin` 登不进后台。完整方案请用 10.2 的 `init_db.py`。
