# 移动端下载 App 设计稿（4KDownle · uniapp + 后端视频处理服务）

> **V1 范围声明**：第一版只做两个核心功能——**① 视频下载**（复制链接 → 解析 → 下载，支持 YouTube / 抖音 / B站 / 视频号等 1000+ 网站）和 **② 框选去水印**（任意时间戳定位 + 多框/移动水印）。去水印只保留「手动框选」一种，不做 AI 去水印。其余功能（加水印 / MD5 修改 / 转 GIF / 导出字幕 / 导出语音）作为首页工具卡片占位入口，点击提示「开发中」。

---

## 一、总体架构

**核心前提**：手机端跑不了 ffmpeg/yt-dlp/Playwright，所有视频处理都在服务器完成。uniapp 只是「壳」——负责 UI、文件上传下载、调后端接口、展示结果。

```
用户(手机/小程序/H5) ──粘贴链接/上传视频──▶ uniapp 前端
                                              │ 调 API
                                              ▼
                                     FastAPI 后端（异步）
                                       ├─ 解析路由：yt-dlp --dump-json / 专用抖音·B站解析器
                                       ├─ 下载路由：yt-dlp 下载 → 转存 OSS → 返回直链
                                       ├─ 去水印路由：抽帧 → 返回帧图 → 收坐标 → ffmpeg 处理
                                       ├─ 任务队列：Celery + Redis（先 asyncio + 内存队列跑通）
                                       └─ 进度推送：SSE / 轮询
                                              │
                          ┌───────────────────┼───────────────────┐
                          ▼                   ▼                   ▼
                     yt-dlp 引擎          ffmpeg 处理         阿里云 OSS
                    (1700+ 站点)      (合并/去水印/转码)    (存储 + CDN)
                          └───────────────────┴───────────────────┘
                                  Playwright（抖音/视频号反爬兜底）
```

**技术栈选型**：

| 层 | 选型 | 理由 |
|----|------|------|
| 前端 | uniapp（Vue3） | 一套代码编译安卓 APK / 微信小程序 / H5 三端 |
| UI 组件库 | **uview-plus** | uniapp Vue3 生态 UI 库（CLI 工程 + easycom 自动注册） |
| 后端 | **Python FastAPI** | Python 视频处理生态好（yt-dlp / moviepy / ffmpeg-python），异步接口 |
| 视频解析 | **yt-dlp** 为主力 | 1700+ 提取器，覆盖 1000+ 站点，长尾站点靠它兜底 |
| 反爬兜底 | Playwright（无头浏览器） | 抖音/视频号反爬强，拦截动态请求拿直链 |
| 抖音专用 | A-Bogus 签名 + ttwid cookie + Referer | 纯 HTTP 解析，无需浏览器（SM3 + RC4 实现） |
| B站专用 | WBI 参数 + 音视频分离 | 拿音视频分离直链，ffmpeg 合并（否则无声） |
| 视频处理 | ffmpeg（子进程调用） | 合并 / 去水印 / 转码 / 抽帧，业界标准 |
| 存储 | 阿里云 OSS + CDN | 大文件上传下载，下载走 CDN |
| 任务队列 | Celery + Redis（先内存队列） | 视频处理耗时，不能同步等 |

## 五、核心功能详细设计

### 1. 视频下载

**实现**：粘贴链接 → 后端解析（`yt-dlp --dump-json`，抖音/B站走专用解析器）→ 选清晰度 → `yt-dlp` 下载 → 转存 OSS → 返回下载链接。

**平台策略**（主引擎 + 备用引擎双保险）：

| 平台 | 首选 | 备用 |
|------|------|------|
| YouTube | yt-dlp | — |
| B站 | yt-dlp | WBI 参数拿音视频分离直链 + ffmpeg 合并 |
| 抖音 | 短链展开(`v.douyin.com`) + A-Bogus 签名 + ttwid cookie + Referer 直链 | Playwright 无头浏览器拦截；yt-dlp 兜底 |
| 视频号 | **高难点**：yt-dlp 支持弱，需 Playwright + 登录态，随时可能失效 | V1 不做，能力预留 |
| 其他 1000+ 站点 | yt-dlp 通用提取器 | — |

**难度**：★★★☆☆

### 2. 视频去水印（框选 · 任意时间戳 · 多框）

#### 处理方式对比

| 方案 | 原理 | 优点 | 缺点 | 难度 |
|------|------|------|------|------|
| **A. 裁剪 crop** | 裁掉水印所在边 | 零痕迹、快 | 损失画面；水印须在边缘 | ★ |
| **B. 模糊 boxblur** | 水印位置打模糊块 | 通用、快 | 留模糊块，不美观 | ★★ |
| **C. delogo 插值**（默认） | 周围像素插值填充 | 比模糊自然 | 水印大时糊 | ★★ |

> AI 修复（ProPainter）划入后续版本付费功能，V1 不做。V1 已实现 delogo + 单框 blur，crop 裁边暂未实现。

#### 坐标映射（关键）

- 前端在**预览静帧上按百分比**记录每个框的矩形 `(x%, y%, w%, h%)`，后端用帧图尺寸换算回原视频像素坐标，再喂给 ffmpeg（`delogo=x:y:w:h` / `boxblur`）。
- **单帧多框**（多水印）：直接传 `boxes[]`。
- **移动水印**：不同时间点各框一次，前端聚成 `segments[]`，后端分段套不同坐标再 `concat` 合并。

**难度**：★★★☆☆

## 六、关键难点汇总（跨功能）

1. 移动端无法本地处理视频 → 全走后端，上传下载大文件是瓶颈。
2. 大文件传输：分片上传、断点续传、OSS 直传。
3. 任务异步化：提交任务 → 轮询/SSE 拿进度 → 完成后下载。
4. 小程序限制：微信小程序对下载/保存相册/上传大文件限制多，部分功能需降级。
5. 反爬维护：抖音 A-Bogus、B站 WBI、视频号登录态都会随平台更新而失效，需持续维护。
6. 合规：视频下载 + 去水印属灰产地带，App Store 基本过不了审 → 主推安卓 APK + H5 + 小程序；iOS 走企业签名/侧载或不承诺上架。

## 八、需要后续确认的点

1. ASR 用哪家云 API（阿里云/讯飞/百度）——阶段 5 才涉及。
2. 上架渠道：App Store 大概率过不了审，是否只做安卓 APK + 小程序 + H5，iOS 走侧载。
3. 服务器部署地区：YouTube 需境外服务器，抖音/B站需境内，是否要分区域部署。
